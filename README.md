# Avito-бот для комплектующих

Telegram-бот: кнопки по дереву из таблицы (Видеокарты → NVIDIA → RTX → 40 → 4060 → RTX 4060 Ti),
на последней кнопке ссылки на объявления Авито, подходящие под цену и фильтры строки.
Каждые N минут бот сам проверяет все модели и присылает новые объявления.

## Запуск (Windows)
1. Установить Python 3.11+ с python.org (галочка «Add to PATH»).
2. В папке проекта: `py -m venv .venv`, `.venv\Scripts\pip install -r requirements.txt`
3. Скопировать `.env.example` в `.env` и заполнить `BOT_TOKEN`, `ALLOWED_USERS`, `CATALOG`.
4. `.venv\Scripts\python -m avito_bot`

Команды бота: `/start` — меню, `/reload` — перечитать таблицу сразу.

## Таблица
См. лист «Инструкция» в таблице. Для Google Таблиц в `.env` указывается ссылка на таблицу
(доступ «Все, у кого есть ссылка → Читатель»). Бот скачивает её целиком при каждом цикле, `/reload` — сразу.
